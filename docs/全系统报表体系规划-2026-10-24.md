# 全系统报表体系规划

日期：2026-10-24。核查基线：本地 v0.55.2 的业务模块与报表代码。本文件为方案，不表示新增报表已实现，也不表示真实业务数据已经齐全。

## 1. 统筹结论

报表体系必须覆盖“订单是否满足、生产是否稳定、库存是否准确、采购是否及时、销售是否收回、资金是否够用、当月是否盈利”。现有系统单据与岗位待办较齐全，分析入口存在重叠，跨环节勾稽不足。

统一为九个主题：经营总览、销售与回款、生产与耗用、采购与供应、库存与盘点、资金与应付、成本与利润、配送与周转筐、人员与工资。主题不等于新增九个菜单；优先复用现有模块与权限，通过页签组织。

经营总览服务老板，专题页服务对应责任岗位。经营指标共用服务端口径，首页仅摘要并链接专题，不能再计算一套结果。单据录入、作业待办、对外凭据、管理分析各有用途；合并报表入口不能删除原始记录和必要作业页面。

## 2. 现有入口的保留、合并与取消

| 当前内容 | 决定 | 目标归属与理由 |
|---|---|---|
| 老板首页与经营看板的重复销售、成本、客户汇总 | 合并分析口径与入口 | 一个经营总览，日/月切换；首页只保留摘要和异常入口 |
| 独立“月度报表”与经营看板中的产品盈利页签 | 合并 | 统一为成本与利润中的“产品经营测算”；后续接正式产品成本。通用“月度报表”命名取消 |
| 销售日报与月报 | 保留统一入口 | 日期粒度切换；客户、产品、地区、市场是同一报表的分析维度，不各建一套 |
| 销售报表内的出品率数据及相应遗留逻辑 | 移出销售主题 | 出品率归生产；销售可链接查看，不另维护生产口径 |
| 生产日报与生产月报 | 保留并统一指标 | 日报处理当日差异，月报看累计与稳定性；按产品/系统下钻 |
| 大豆分析、生产日报中的库存质量、老板生产页中的品种构成 | 合并数据与明细 | 库存专题保留完整批次与质量，其他页面只放与当次决策有关的摘要 |
| 采购付款、费用付款、员工工资、外购成品付款 | 保留作业入口，合并应付分析 | 财务有统一付款安排；不能把不同来源的支付审批合成一个无来源余额 |
| 产品应收与豆渣应收 | 合并经营汇总，保留来源与凭据 | 客户统一观察，产品/豆渣分别核对，不重复计算 |
| 费用分类汇总与费用付款台账 | 均保留，区分认列与现金 | 费用按所属期；付款按实际发生日。两表不能互相替代 |
| 月考勤表、工资表、工资条 | 保留 | 管理分析、核算依据、个人凭据用途不同；工资明细严格按权限 |
| 配送总单、客户对账单、豆渣结算单、运输结算单、供应人结算单 | 保留 | 是执行或对外核对凭据，不因“报表精简”而取消 |
| 岗位首页待办与全公司异常提示 | 保留并共用规则 | 全公司看到责任与影响，员工看到本人可处理事项；同一单据涉及多流程不能当成独立订单累加 |
| 审计、权限、备份健康 | 保留在行政/运维 | 老板总览只提示重大故障，不占据经营分析主体 |

取消的是重复独立入口、重复计算与没有决策用途的图；不是删除历史单据、现有权限或审计链。

## 3. 必须补齐的报表与核对视图

“缺失”包括已有单据或局部列表，但尚未组成完整的跨环节报表。以下均应建设，不要求每项单独开菜单或配一张图。

| 优先级 | 必须建设项 | 读者、决定 | 最小内容 | 现状与数据前提 |
|---|---|---|---|---|
| P0 | 订单与实发差异 | 老板/库管：哪些需求没有满足，是否调整备货 | 订货、拟配、实发、差额、客户/产品/日期、未完成阶段 | 已有数量与分配数据；差额原因不全时标待核实。不能把所有差额认定缺货损失或销售机会损失 |
| P0 | 销售到回款核对 | 会计/出纳：哪些货尚未形成账款，哪些账尚未收回 | 已实发未称重、待算票、待复核、已复核发货、退货扣款、折让、实际收款、当前未收 | 已有订单状态、退货、核销与收款；历史期初待核定，当前余额与历史时点余额分开 |
| P0 | 退货、扣款与处置闭环 | 老板/厂长/会计：哪些产品、客户、原因反复出现问题 | 收到日、原单归属、原因、数量/公斤、核定金额、待处理、抵账/退款、隔离余量和处置 | 已有原因、原单关联、隔离与处置。退货货款、报损成本、库存差异不直接相加，避免同一事件重复统计损失 |
| P0 | 库存收发存与盘点差异 | 库管/会计：账实是否一致，哪里持续损耗 | 期初、自产、采购、转入、转出、实发、报损、账存、实盘、盘差、原因、未日结 | 已有日结与台账。可售与退货隔离分开，原辅料/自产/外购分别列，数量按单位与产品核对 |
| P0 | 月结完整性及成本勾稽 | 会计：本月是否可结、测算是否可信 | 未计价批次、未分摊材料、未复核销售/退货、未录费用、库存未结、未归属资金、工资与费用差异 | 已有各来源数据，需建立跨模块核对。工资核算、所属期工资费用、实发工资分别列；不能因已发工资再记一次成本 |
| P0 | 月度利润表 | 老板/会计：本月实际盈利多少、原因是什么 | 收入、营业成本、税金及附加、销售/管理/财务等费用、其他损益、所得税费用、净利润；附编制状态 | 必须建设；先补自产成品成本结转、完整费用计提、税费与其他损益、期初与期间结账。数据齐前显示测算及缺项，不能伪装为正式净利润 |
| P1 | 采购到货与实际成本 | 采购负责人/会计：何时催货、哪些采购价格变化需核查 | 预计到货、实际分批到货、未到余量、逾期未到、关闭余量、货款、运卸、实际入库单价 | 原辅料已具备预计到货与分批验收；外购成品按自身数据能力分列。比较价格须同品种、规格、单位和费用范围 |
| P1 | 实际资金收支与付款安排 | 老板/出纳：近期必须支付多少、需要准备多少资金 | 账户账面余额、实际收支、未关联流水、已到期应付、未来7/14日已知付款、无到期日清单 | 已有资金与多来源应付，但缺完整银行核对、付款计划和回款承诺。先做“已知付款安排”，计划与实际分开，不能承诺准确现金预测 |

第一批优先补前五项，形成业务和数据核对能力；月度利润表的基础建设同时启动。采购与资金安排随后接入，不能用增加漂亮图表替代闭环。

## 4. 九个主题的最终边界

| 主题 | 必须回答的问题 | 页面内容与表现 |
|---|---|---|
| 经营总览 | 今天异常在哪里？本月收入、成本、资金情况如何？ | 3–4个关键数＋关键异常；日/月明确切换。最多3张有必要的图，所有数可追到专题 |
| 销售与回款 | 发了什么、退了什么、谁没收回、哪里需求下降？ | 发货/退货/净额、客户与产品、订单实发差异、回款核对。复购变化作为经营线索，不能直接断言流失或动销 |
| 生产与耗用 | 哪个系统/产品出品异常，依据是否可信？ | 同口径出品率、实际用豆、供浆分摊、转加工出品率、报损、缺项。普通自产与转加工分别解释 |
| 采购与供应 | 哪些货没到、实际采购成本怎样变化？ | 到货跟踪、可比入库成本、供应商交易与应付来源；采购量与付款额分开 |
| 库存与盘点 | 可用货有多少、账实差在哪里？ | 收发存、盘差、隔离退货、库存预警、大豆批次质量。存货金额对未计价部分单列 |
| 资金与应付 | 钱从哪里来、花在哪里、下一笔该付谁？ | 实际收支、账面余额、已知付款安排、统一应付清单。内部转账排除经营收支 |
| 成本与利润 | 当月成本是否完整，产品贡献如何，当月净利润多少？ | 成本构成、月结核对、阶段性产品测算、正式利润表。管理测算与结账报表明确编制状态 |
| 配送与周转筐 | 哪些配送差异未解决，哪些筐未回？ | 实际趟次、运输费、漏送/多送反馈、回筐待确认、客户欠筐、司机车辆差异。反馈解决不自动等于财务差额已核销 |
| 人员与工资 | 排班是否到位、考勤是否完整、工资是否算准付清？ | 排班/实际考勤、应发/实发/未发、核算依据变化、费用勾稽；暂不做未经工时与可比产出支撑的员工效率排名 |

## 5. 哪些内容当前不应出现

### 应当取消或改名的当前呈现

- 用“盈利、净利”命名尚未完整结转的产品测算：现有部分导航/说明仍保留此类措辞，统一改为“经营测算”，待正式核算上线后再使用利润术语。
- 把所选历史日期产生订单的“当前未收”写成该历史日期的应收余额：需说明查询口径；未建立历史余额重建前不得暗示历史冻结快照。
- 未登记成本以零进入数字汇总，却只把风险留在可折叠脚注：主数字应同步显示不完整状态。
- 在客户、产品、市场筛选后的明细上方放未同步筛选且未标明范围的图：统一范围或明确标“全地区概览”。
- 每个页签重复出现相同趋势/排名；仅重复表格信息、无法触发行动的构成图；为追求丰富给所有报表加图。

### 需先补基础数据，之后再建设

| 报表/指标 | 当前不能直接成立的原因 | 正确建设路径 |
|---|---|---|
| 自产产品毛利、净利润 | 自产成品成本尚未完整入库、跨期结转；税费与费用口径不完整 | 建自产成品计价、销货成本结转、费用计提、税费及其他损益、月结与调整机制，出月度利润表 |
| 临期、批次保质期和召回追溯 | 缺统一自产成品批次、生产日期、有效期及发货批次分配 | 先建批次和有效期流程，之后做临期与追溯；原料库存批次不能替代成品批次 |
| 门店动销、售罄率 | 系统主要掌握发货与退货，没有门店销售回传 | 建回传机制并核对覆盖范围，现阶段使用发货口径 |
| 客户合同逾期率、DSO等正式回款效率 | 合同账期、期初、历史时点余额等需完善 | 先做当前未收与账龄预警；账龄大不自动等于违反合同逾期 |
| 配送准时率、签收及时率 | 没有完整承诺送达时间与实际签收事件 | 补时点与签收凭据，当前只报已记录的配送安排、称重和反馈 |
| 供应商质量合格率 | 检测指标不等于完整检验结论，缺覆盖一致的合格标准和验收样本 | 明确检验项目、批次数、阈值、结果及未检项后建设 |
| 产能利用率、OEE、标准工时效率 | 缺额定产能、运行/停机/工时和可靠良品量 | 先采集设备和工序事件，不用浆缸数、考勤人数替代 |
| 自动渠道分析与农历节庆同比 | 缺渠道字段、农历事件映射 | 建字段及映射；已有市场/地区可分析，公历对比必须注明 |

这些是建设前提，不是永久禁止。尤其净利润，应列为必建财务结果，而不是长期停留在测算。

## 6. 净利润如何落地

净利润需要的是完整核算链，而不是在现有差额旁换名称。

1. 核定期初：原辅料、自产成品、外购成品、应收应付、资金、未结成本；如有在产品，另建范围与计价。
2. 自产成本入库：实际材料、可归属人工、制造费用按已确认规则归集到产品；不能将全部生产人工先计产品成本、再重复列期间费用。
3. 销货成本结转：库存未售部分留在存货，售出部分转营业成本；退货按规则冲回，报损单列。外购成本链继续复用。
4. 费用与负债按所属期间计提：工资、能源、租金、折旧等按归属期入账；实际付款冲应付，不再次增加费用。直接/制造/期间费用分类要统一。
5. 明确收入、价税和税费口径，补其他收益/损失、财务费用及所得税费用等必要科目；具体科目与规则由会计按企业实际情况维护，不能从金额或客户名猜测。
6. 月结前执行勾稽，月结后保存报表版本与编制状态；跨期退货、补票和调整通过受控调整留痕，不静默改写已结报表。

对老板的结果应分为“未结测算”和“已结月度利润表”；应同时展示收入、成本、利润和实际收付款，盈利不等于已收到现金。

## 7. 实施与验收

方案顺序：先统一主题与指标字典，再补跨环节核对，随后建设利润核算基础，最后增加确有价值的趋势、比较和预警。未经确认不删除稳定模块编号和历史授权。

每个指标必须定义：来源、粒度、单位、所属日期、当前或历史状态、计入与排除条件、缺失处理、责任岗位、下钻入口。服务端使用整数分/Decimal聚合，按权限裁剪金额，前端只渲染；CSP、离线、手机、打印及无障碍沿用现有约束。

验收要求：数字可回到原单；跨报表同口径一致；缺失与零分开；不同数量单位不混加；待办不重复当成独立业务数；退货/费用/付款不重复计损；历史与当前状态明确；无权限接口不泄露金额；月结报表可复核与追溯；手机320px、键盘及打印能独立使用。

## 2026-10-27费用成本口径补充

v0.86.0不定期费用月结按对应费用项目补齐未覆盖日期。本月按实际区间金额日均，缺实际则沿用最近一期实际账单并显示来源。原已结月份不改，实际与已确认补充的差额计入本次登记月，允许负数冲减；日均只含当月实际区间金额，不含上期差额。实际应付仍为整笔账单，月结补充不进入应付、实付或现金流。旧已结利润测算快照保持不变，新实际账单与补充依据可追溯；仍不是正式成本结转和完整净利润表。
