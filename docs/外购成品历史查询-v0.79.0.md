# 外购成品历史查询 · v0.79.0

本批只补外购成品的历史查询入口，把原来“按月台账 + 浏览器内供应人过滤”改为服务端日期、供应人、状态和搜索筛选，并增加全量汇总与稳定分页。月度成本、订单余量、算票、付款、退款、结算单和打印逻辑不变。

## 入口

- 财务管理 → 应付与采购付款 → 外购成品 / 供应人结算 → 历史查询。
- 进入后页面标题为“外购成品历史”，原“返回本月台账”按钮回到当前业务月份的验收与付款台账。
- 历史页为只读查询；登记付款、补计价、退货、退款和结算单仍在原台账及对应入口办理。

## 查询规则

- 日期：默认为今天所在自然月；可改起止日期，最长 3652 天。
- “全部日期”勾选后忽略起止日期，查询全部历史。
- 供应人：按原验收单的供应人筛选。
- 状态：
  - 待计价：尚未补齐采购价格，或等待重算。
  - 未付清：应付净额大于实际付款。
  - 已付清：应付净额等于实际付款。
  - 多付 / 应退：实际付款大于应付净额。
- 搜索：验收单号、供应人、供货单号、备注、经办人、订单号、产品名。
- 每页固定 50 单，按验收日期倒序、单号倒序；翻页只取当前页明细。

## 汇总口径

- 验收货款：原验收单金额合计（退货前）。
- 退货冲减：未作废退回单金额合计，以正数展示，从应付中扣减。
- 应付净额：验收货款减退货冲减。
- 已付：付款合计减退款合计。
- 未付 / 应退：应付净额减已付；负数为供应商应退。
- 待计价单数：待计价验收单数量，金额不按零成本强行计入应付。
- 汇总覆盖全部筛选结果，不受当前页限制；表格只展示当前页。

## 接口与权限

- `GET /api/finished-goods?view=history&start=YYYY-MM-DD&end=YYYY-MM-DD&supplier_id=&status=&search=&page=1&page_size=50`
- `all=1` 查询全部日期；不能同时传起止日期。
- 权限沿用 `finance.payables`，并需要 `purchase-prices` 采购金额数据范围；无权限返回 403，参数错误返回 400。
- 无数据库结构变更，沿用 schema 61 和既有 `finished_goods_records` 索引。

## v0.86.0：按费用项目月结补齐与登记月差额（2026-10-27）

用户确认的不定期费用规则取代v0.85独立暂估操作：在费用项目属性维护或登记成本费用勾选，填写详细日期及计量标识。页面顶部“本月结账”打开逐费用项目核对表，显示实际区间、已补区间、待补空档和来源日均。本月日均采用本月实际区间金额÷已覆盖天数，不含以前月份划来的差额；本月无实际账单，沿用最近一期实际账单的全额÷覆盖天数。均按分四舍五入，连续空档按整数分配，零分自动补充仍保存覆盖日期。
